# v0.1.0-phase1 — Module Version Sanity Check

_Scan run: 2026-04-23, on develop @ tag-prep time._

## What was checked

Every `src/Kun.*/Kun.*.csproj` was scanned for local
`<Version>`, `<VersionPrefix>`, `<VersionSuffix>`, or `<PackageVersion>`
overrides, and for `<IsPackable>` status.

```bash
grep -n -E "<(Version|VersionPrefix|VersionSuffix|PackageVersion)>" src/Kun.*/Kun.*.csproj
```

## Result

**No per-project version overrides exist.** All 24 `src/Kun.*` projects
inherit `VersionPrefix=0.1.0` + `VersionSuffix=phase1` from
`Directory.Build.props`. A single `dotnet pack` on any packable
module emits a `*.0.1.0-phase1.nupkg` + matching `.snupkg`.

Verification: `dotnet pack src/Kun.Core` → `Kun.Core.0.1.0-phase1.nupkg`.
